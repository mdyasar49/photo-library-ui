Version 3.0 represents a complete technical and visual overhaul, introducing **Monorepo-ready architecture** and **Bytecode Inspection tools**.

## ✨ Highlights in v3.0
- **🍏 Premium Glassmorphism**: Overhauled the UI with frosted glass sidebars, dynamic stats dashboards, and deep blurred backgrounds.
- **📊 Storage Shield Dashboard**: Real-time visualization of library storage usage (MB) and asset counts.
- **🛡️ Bytecode Inspector**: A dedicated transparency view to inspect the raw hex bytecode of any secured image.
- **🎭 Multi-Select & Bulk Actions**: Select multiple photos at once for bulk deletion or categorized management.
- **📂 Smart Navigation**: Independent folder views with individual ZIP download capabilities.

## ⚙️ Installation & Setup
1. `npm install`
2. `npm run dev`
